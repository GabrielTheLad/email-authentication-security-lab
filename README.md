# Email Authentication Security Lab
Hands-on Microsoft 365 email authentication lab implementing and validating SPF, DKIM, and DMARC for a custom domain, with DNS configuration, header analysis, testing, and security findings.

## Overview

This project documents the implementation and validation of email authentication controls for a custom domain using Microsoft 365 and external DNS management.

The lab focuses on:

- SPF
- DKIM
- DMARC
- Email authentication alignment
- Message header analysis
- Controlled authentication testing
- DMARC policy enforcement

## Lab Environment

- Domain Registrar / DNS: Spaceship
- Email Platform: Microsoft 365 / Exchange Online
- Test Environment: Controlled mailboxes and domains

## Project Objectives

1. Configure SPF for authorized Microsoft 365 mail flow.
2. Configure DKIM signing for the custom domain.
3. Deploy DMARC initially in monitoring mode.
4. Validate SPF, DKIM, and DMARC through real email traffic.
5. Analyze message headers and authentication results.
6. Test authentication and alignment scenarios.
7. Progress DMARC toward stronger enforcement where appropriate.
8. Document findings, limitations, and security implications.
